# Аян емхана конструкторы

Аян емханасының жаңа 2 қабатты ғимаратын эскизге дейінгі кезеңде жобалауға арналған анимациялы 3D конструктор.

## Мүмкіндіктері

- **3D модель** — құрылыс анимациясы, қабаттарды ажырату, қасбет көрінісі, айналдыру/масштаб.
- **Қабат жоспары** — бөлмелер атауы мен ауданы, пациент ағындары (ересек, балалар, жедел жәрдем, медқалдық), кіреберістер.
- **Фон таңдау** — Студия, Аспан, Дала, Жасыл учаске, Ватман, Сызба, Түн.
- **Кабинет редакторы** — атауы, мақсаты, саны, ауданы, биіктігі (көлемі есептеледі), бөлімшесі, дәліз жағы, реті. Жоспарда кабинетті сүйреп басқа кабинеттің орнына ауыстыруға болады.
- **Бөлімшелер** — қабат/қанат ауыстыру, ретін өзгерту, бөлме қосу/жою, жаңа бөлімше.
- **Қуат есебі** — тіркелген халықтан учаске саны мен ауысымға бару.
- **Тексеріс** — ҚР ДСМ-96/2020 және бағдарлық нормалар бойынша автоматты ескертулер.
- **Экспорт** — бөлмелер кестесі (CSV, Excel үшін) және жоба (JSON). Нұсқалар браузерде сақталады.

## Іске қосу

`index.html` файлын браузерде ашыңыз немесе GitHub Pages арқылы жариялаңыз. 3D үшін three.js (r128) cdnjs-тен жүктеледі.

## Ескерту

Бұл — эскизге дейінгі бағдарлама құралы. Аудандар осьтер бойынша (қабырға қалыңдығынсыз) есептелген. Түпкілікті шешім — лицензиясы бар жобалаушы, ҚР құрылыс нормалары және сараптама. «Ұсыныс» және «болжам» белгісі бар мәндер нақтылауды қажет етеді.

Нормалар көзі: [ҚР ДСМ-96/2020](https://adilet.zan.kz/rus/docs/V2000021080); ҚР құжатында сан жоқ жерде РФ СанПиН 2.1.3678-20 бағдар ретінде алынды.
